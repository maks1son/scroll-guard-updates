# Scroll Guard updates

Signed Android APK releases and the public update manifest for Scroll Guard.

The app checks `releases/latest/download/update.json`, downloads a newer APK and verifies its package name, version, SHA-256 digest and signing certificate before asking Android to install it.

Signing certificate SHA-256: `3bdee5852238e66b7bc71bf2a2c024eaa007900b3d0bea669b3cb7cc55427b72`.

App data, viewing history, account names and diagnostics are not uploaded to this repository. Source code and signing keys are not stored here.
